Arcade street racing in the browser, NFS Heat style. Three.js, zero external assets: every texture,
mesh and sound is generated at runtime.

**Play:** https://arda-avci.github.io/driver/

Controls: W/↑ throttle · S/↓ brake/reverse · A D / ← → steer · Space handbrake (drift) · Shift nitro ·
hold R reset car · Esc pause · M mute · 1 2 3 time of day. Touch controls on phones.

This repository holds the built site only.
